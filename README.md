# Atode

PCとスマホから記事・ワード・リンクをすぐ保存できるメモアプリ（PWA）。

- 保存先: 端末内 + Dropbox（アプリフォルダの `atode.json` / `atode.md`）
- `atode.md` は鍵付きクリップを除いた一覧。Claude の Dropbox コネクタから読める
- 鍵付きクリップは合言葉（PBKDF2 + AES-GCM）で端末内で暗号化してから保存
- 追加方法: 入力欄 / Android の共有メニュー / PC のブックマークレット / iPhone のショートカット
- Google Keep の Takeout ZIP を読み込み可能（パスワードらしきメモは自動で鍵付きに）
- リンクのプレビュー（タイトル・画像）は microlink.io から取得し、端末内にキャッシュ（鍵付きクリップは対象外）

## 操作

- 削除したクリップはゴミ箱に30日残り、その後に完全に削除される
- 同じURLを保存すると、新しいカードは作らず既存のカードを先頭へ移す
- PCのキーボード: `/` 検索、`N` 入力欄、矢印キー（または `H` `J` `K` `L`）でカード移動、`Enter` 編集、`O` リンクを開く、`P` ピン留め、`E` アーカイブ、`U` 既読/未読、`X` 選択、`Delete` 削除
- PCでは画面へのドロップや、入力欄の外での貼り付け（Ctrl+V）でも保存できる
- タグを右クリック（スマホは長押し）すると、色・名前の変更（既存のタグ名にすると統合）・削除ができる
- 設定の「Dropboxの履歴から復元」で、`atode.json` の過去のバージョンに戻せる（その時点になかったクリップはゴミ箱へ移る）

## スマホ

- Android（Chrome）: メニューの「アプリをインストール」（または設定の「アプリとしてインストール」）でホーム画面に追加すると、共有メニューに Atode が出る
- iPhone: Safari の共有 →「ホーム画面に追加」。PWA は共有先に出られないので、ショートカットで Dropbox の `/アプリ/Atode/atode-inbox.txt` に1行ずつ追記し、Atode が次の同期で取り込んで消す（行は URL エンコード可）

## Chrome拡張

- ソースは `extension/`。`extension/` を変更して main にマージすると、GitHub Actions が `atode-extension.zip` を作り、リリース `extension-v<バージョン>` に添付する
- 更新時は `extension/manifest.json` の `version` を上げる（同じバージョンのままだと既存リリースの zip を差し替え）
- インストール: zip を展開 → `chrome://extensions` → デベロッパーモード →「パッケージ化されていない拡張機能を読み込む」で展開したフォルダを選ぶ
